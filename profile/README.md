### The problem

Everyone is a developer now. Coding agents run shell commands, read repositories and reach MCP
servers on their own — and approving every one of those calls by hand does not scale. Security
teams lose sight of what agents did, on whose behalf, and with what reach.

### What Spectis watches

- **Coding agents** — every session, tool call and verdict, taken from the agent runtime itself
- **MCP servers** — what is installed, what changed, and what is allowed to run
- **Endpoints & repositories** — AI tooling and agent artifacts actually present on machines
- **AI services** — adoption, spend and conversation governance across providers

Audit events ship to the SIEM you already run.

**Observes, never intercepts.** No proxy in the traffic path, no added latency, and nothing that
conflicts with existing SASE or egress infrastructure.
